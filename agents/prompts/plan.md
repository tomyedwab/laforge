If there is no plan in .pr/plan.md, create one based on the discussion in the
PR. If there is a plan, review any discussion in the PR and make any updates to
the plan as necessary. DO NOT IMPLEMENT ANYTHING YET.

Things to look for:
- Ambiguous or unstated requirements: Propose clarifications, but ask for guidance before doing too much detailed planning.
- Technical decisions that will need to be made: Do research as necessary and present alternatives with pros/cons for review.

A great plan should lay out explicit requirements, a proposed technical
approach, comprehensive task breakdown, and sketched out testing/validation
approach.
